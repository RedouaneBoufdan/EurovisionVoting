Current architecture

Each selected country datacenter runs as its own Docker container and generates votes independently. The central aggregator receives all events, stores the raw CSV votes, and the dashboard updates through API calls without a full page reload.

How the test works

The dashboard sends one command to the central aggregator. The central aggregator resets the CSV files and starts the selected Docker datacenter workers.

  1. Each selected datacenter receives its part of the total votes.
  2. The worker sends votes gradually during the selected duration.
  3. The central aggregator stores raw votes in CSV and updates the global ranking.

How to start the project

Run these commands from the project folder.

docker compose down --remove-orphans
docker compose up --build

Then open:

http://localhost:8501

Useful commands to operate the system

docker compose ps
docker compose logs -f central-aggregator
docker compose logs -f dc-belgium
docker compose logs -f dc-france
docker compose logs -f dc-germany
docker compose logs -f dc-italy

You can replace dc-belgium with any country service, for example dc-spain, dc-netherlands, dc-ukraine or dc-estonia.

Stop everything cleanly:

docker compose down

Docker network explanation

In Docker, the browser uses localhost:8501. The containers communicate internally with service names. central-aggregator is internal Docker DNS, so you should not open it directly in the browser. Datacenter workers use URLs like dc-belgium:9000, dc-france:9000 and dc-germany:9000 inside the Docker network.
